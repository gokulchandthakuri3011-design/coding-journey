# Java Learning Journey (1 Hour/Day)

Welcome to your Java learning journey! This plan is designed for beginners who can dedicate 1 hour each day to learning and practicing Java. It's structured over 30 days to build a solid foundation.

## Week 1: Java Basics & Setup
**Goal:** Understand the syntax and basic constructs of Java.

*   **Day 1: Introduction & Setup**
    *   Install the Java Development Kit (JDK) and an IDE (IntelliJ IDEA or Eclipse).
    *   Write, compile, and run your first "Hello World" program.
    *   Understand the difference between compilation (`javac`) and execution (`java`).
*   **Day 2: Variables & Data Types**
    *   Primitive data types (`int`, `double`, `boolean`, `char`).
    *   String basics.
    *   Declaring, initializing, and using variables.
*   **Day 3: Operators & Input**
    *   Arithmetic operators (`+`, `-`, `*`, `/`, `%`).
    *   Relational operators (`==`, `!=`, `<`, `>`).
    *   Logical operators (`&&`, `||`, `!`).
    *   Reading user input with `Scanner` and `nextLine()`, `nextInt()`.
*   **Day 4: Control Flow (Conditionals)**
    *   `if`, `else if`, `else` statements.
    *   Ternary operator (`condition ? valueIfTrue : valueIfFalse`).
    *   `switch` statements.
*   **Day 5: Control Flow (Loops)**
    *   `for` loops.
    *   `while` and `do-while` loops.
*   **Day 6: Arrays (1D)**
    *   Declaring and initializing arrays.                            
    *   Accessing and modifying array elements.
    *   Iterating over arrays using loops.
*   **Day 7: Methods (Functions)**
    *   Defining methods, parameters, and return types.
    *   Calling methods from `main`.
    *   Understanding variable scope.

## Week 2: Object-Oriented Programming (OOP) - Part 1
**Goal:** Grasp the core concepts of Object-Oriented Programming in Java.

*   **Day 8: Classes and Objects**
    *   What is a class? What is an object?
    *   Creating classes and instantiating objects.
    *   Instance variables vs. local variables.
*   **Day 9: Constructors**
    *   Default constructors.
    *   Parameterized constructors.
    *   The `this` keyword.
*   **Day 10: Access Modifiers & Encapsulation**
    *   `public`, `private`, `protected`, and default modifiers.
    *   Creating Getters and Setters.
    *   Why encapsulation is important for data security.
*   **Day 11: The `static` Keyword**
    *   `static` variables (class variables).
    *   `static` methods.
    *   When and why to use `static`.
*   **Day 12: Inheritance**
    *   The `extends` keyword.
    *   Superclasses and subclasses.
    *   The `super` keyword to call parent constructors and methods.
*   **Day 13: Polymorphism (Compile-time)**
    *   Method overloading.
    *   Constructor overloading.
*   **Day 14: Polymorphism (Runtime)**
    *   Method overriding.
    *   The `@Override` annotation.
    *   Upcasting and downcasting (basics).

## Week 3: Object-Oriented Programming (OOP) - Part 2 & Core APIs
**Goal:** Master advanced OOP concepts and essential Java utility classes.

*   **Day 15: Abstraction**
    *   Abstract classes and abstract methods.
    *   When to use abstraction instead of concrete classes.
*   **Day 16: Interfaces**
    *   Defining and implementing interfaces (`implements` keyword).
    *   Achieving multiple inheritance behavior through interfaces.
*   **Day 17: Packages & Imports**
    *   Organizing your code into packages.
    *   Importing built-in Java packages (e.g., `java.util`).
*   **Day 18: String Manipulation Mastery**
    *   Important `String` methods (`length`, `substring`, `equals`, `toLowerCase`, etc.).
    *   Immutability of Strings.
    *   Using `StringBuilder` for efficient string manipulation.
*   **Day 19: Exception Handling - Basics**
    *   What is an exception?
    *   Handling errors gracefully using `try`, `catch`, and `finally` blocks.
*   **Day 20: Exception Handling - Advanced**
    *   The `throw` and `throws` keywords.
    *   Checked vs. Unchecked exceptions.
    *   Creating your own custom exceptions.
*   **Day 21: Wrapper Classes & Autoboxing**
    *   Wrapper classes (`Integer`, `Double`, `Boolean`, etc.).
    *   Autoboxing (primitive to object) and unboxing (object to primitive).

## Week 4: Collections Framework & File I/O
**Goal:** Learn how to store dynamic groups of data and read/write to files.

*   **Day 22: Introduction to Collections & Generics**
    *   What is the Collections Framework?
    *   Basic understanding of Generics (`<T>`) to ensure type safety.
*   **Day 23: Lists**
    *   Using `ArrayList`.
    *   Adding, removing, and iterating over list elements.
*   **Day 24: Sets**
    *   Using `HashSet`.
    *   Understanding how sets guarantee unique elements.
*   **Day 25: Maps**
    *   Using `HashMap`.
    *   Storing and retrieving data using Key-Value pairs.
*   **Day 26: File I/O - Reading Files**
    *   The `File` class.
    *   Using `Scanner` or `BufferedReader` to read text from a file.
*   **Day 27: File I/O - Writing Files**
    *   Using `FileWriter` and `BufferedWriter` to save data to a file.
*   **Day 28: Mini-Project Day 1 (Planning & Setup)**
    *   Plan a simple console application (e.g., a Library Management System, a To-Do List, or a Contact Book).
    *   Set up classes and basic menu logic.

## Week 5: Putting It Together
**Goal:** Apply what you've learned and touch upon modern Java features.

*   **Day 29: Mini-Project Day 2 (Implementation)**
    *   Implement data storage (using Collections).
    *   Implement basic logic (adding, viewing, deleting items).
*   **Day 30: Mini-Project Day 3 (Refinement & File Storage)**
    *   Save your application data to a file so it persists between runs.
    *   Handle potential exceptions (e.g., bad user input).

---

### 💡 The "1-Hour Daily" Breakdown Strategy:
To make the most of your 1 hour, try dividing it like this:

1.  **15-20 Minutes: Theory & Concepts.** Read a tutorial, watch a video, or review documentation on the daily topic.
2.  **30-35 Minutes: Hands-on Coding.** This is the most important part. Write code from scratch, experiment, make mistakes, and fix them. Do not just copy-paste.
3.  **5-10 Minutes: Review.** Write comments in your code explaining what it does. Summarize what you learned in your own words.
